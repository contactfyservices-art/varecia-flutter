Place ici tes fichiers audio :
- success.mp3 (son court pour les actions réussies)
- error.mp3   (son court pour les erreurs)

Ce fichier README.txt existe uniquement pour que le dossier assets/sounds/
soit bien suivi par Git (un dossier vide n'est pas versionné par Git et
disparaîtrait lors du push sur GitHub, ce qui casserait la référence
"assets/sounds/" dans pubspec.yaml).

Tu peux supprimer ce fichier une fois que success.mp3 et error.mp3 sont ajoutés.
